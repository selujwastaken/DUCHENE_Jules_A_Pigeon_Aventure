# DUCHENE_Jules_Pigeon_Adventure_Main

prenez vie dans la peau d’un **pigeon explorateur de l’espace**.
Après avoir percuté un astéroïde, vous vous crashez sur une planète inconnue, remplie de rochers et de plantes, mais aussi surveillée par des robots protecteurs de cette flore.

**Votre objectif ?**

Réparer votre vaisseau, et peut-être… une autre forme vie sur ce lieu vas vous aider.
Explorez, survivez, echappez vous.

**Bugs attendus :**

*Collision :*  Il est possible de se coincer dans les colliders du décor.

*Pas de collider :* Un endroit est volontairement sans collider pour faciliter le passage.

*Ennemis bloqués :* Les ennemis peuvent parfois se coincer dans les collisions (c’est rare, mais ça arrive).

*Infos :* les textes peuvent se décaler pour aucune raison.

**Tips :**

- Gardez plus de 6 dynamites dans votre inventaire, vous ne voulez pas rester coincé dans cet endroit.
- Les petits robots spawnent plus rapidement que les autres, ils sont donc utiles pour avoir plus de chances de loot des graines (soins).
